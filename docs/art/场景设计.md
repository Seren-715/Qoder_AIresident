## 1. 鸭子住什么房子

参考图好看的原因不是「石头」本身，而是：**一个天然的、圆润的外壳里，塞进了上下两层手工搭建的生活空间。**鸭子的家要找一个同样「合理又有故事」的外壳：

| 方案 | 合理性 | 优点 | 缺点 |
|---|---|---|---|
| **池塘边的船屋（推荐）** | 鸭子当然住水边 | 地板上能开一个「水口」直通池塘，鸭子可以泡水，这是别的宠物做不了的事；门外是小码头，「出门旅行」就是划船出发，故事自洽 | 无 |
| 倒扣的旧木桶屋 | 一般 | 圆形内部很可爱 | 空间小，放不下阁楼和那么多家具 |
| 程序员书桌上的小屋 | 呼应小黄鸭调试法 | 和 Qoder 关系最直接 | 室内生活感弱；更适合做开场页 |

**推荐船屋**，和参考图的「石头屋」区别也够大：木结构、有水、有码头，一眼就是另一个世界。

## 2. 布局设计

竖屏 9:16，从斜上方俯视。从上到下分三段：

| 区域 | 位置 | 放什么 |
|---|---|---|
| 上段 | 顶部 ~35% | 斜屋顶下的**阁楼**，放床；右侧后墙是**记忆墙** |
| 中段 | 中部 ~25% | 后墙一排：**书架**（左）、**圆窗 + 书桌和小电脑**（中）、**梯子**通阁楼、**任务公告板**（右） |
| 下段 | 下部 ~40% | 木地板：中央**地毯**，左下**水口**（地板开口，直通池塘），旁边**饭碗**，右侧**门**通小码头；最下方一排**前景栏杆和芦苇盆栽**，制造层次 |

**四个角留给界面**（线框图中的红色虚线框），这些位置不要放重要家具：左上状态条、右上菜单、左下快进和日记、右下投喂 / 摸摸 / 聊天。

### Qoder 元素放在哪

| 家具 | 对应 Qoder | 用途 |
|---|---|---|
| 任务公告板 | Quest Mode | 出门前从板上揭下一张旅行任务卡；放在门旁边，动线顺 |
| 书架 | Repo Wiki | 装饰；书脊上可以画几本「Wiki」 |
| 记忆墙 | Memory | 旅行带回的明信片钉在这里，越来越满（可以做成真正会变化的界面元素） |
| 书桌 + 小电脑 | 写代码 | 屏幕上亮着几行代码；电脑上贴一张 Qoder 贴纸 |

## 3. 鸭子锚点（对应线框图的黄色编号）

| 编号 | 位置 | 活动 | 姿态 |
|---|---|---|---|
| 1 | 阁楼床上 | `sleep` 睡觉 | 侧躺盖被子 |
| 2 | 书桌前 | `read` 看书 / `code` 写代码 | 坐着捧书 / 背对镜头敲电脑 |
| 3 | 地毯中央 | `play` 打滚 | 四仰八叉 |
| 4 | 水口边缘 | `gaze` 发呆 | 坐在边上，脚垂进水里，望着水面 |
| 5 | 水口里 | `swim` 泡水（**新增，可选**） | 浮在水面上 |
| 6 | 饭碗旁 | `eat` 吃饭 | 埋头吃 |
| — | 门上 | `away` 出门旅行 | 不出现，门上钉一张小纸条 |

- 「发呆」从窗边改到了水口边，更有鸭子味，也让画面下半部分更热闹。
- 「泡水」是船屋独有的活动，非常适合 Qoduck，建议加进第一阶段 Spec（多一张贴图、多一行数值，工作量很小）。待你确认。
- 锚点之间距离要拉开，最终坐标以生成的背景图为准。

## 5. 变体：池塘边的大树洞

### 合理吗

合理，而且有真实依据：**鸳鸯、林鸳鸯这类鸭子在野外就是在水边的树洞里筑巢的。**帖子里可以写一句「真的有鸭子住树洞」，是个好梗。

### 要注意的

参考图里有一根贯穿屋子的大树干、一圈螺旋的蘑菇台阶、灰色石头墙。树洞本身是很常见的设定，但画风、竖屏俯视、阁楼和梯子我们都借鉴了，**如果外壳再像，整体就会太接近**。所以树洞版要刻意拉开：

| 参考图有的（避开） | 我们的树洞版（改成） |
|---|---|
| 灰色石头墙 | **暖色木头内壁**，墙上能看到一圈圈年轮和树皮纹理 |
| 屋里立着一根树干 | 我们本身就在树干**里面**，墙是弧形的，没有立柱 |
| 螺旋蘑菇台阶 | **绳梯**或树根自然形成的台阶，不画蘑菇台阶 |
| 方形格子窗 | 高处一个**树节孔**当圆窗，透进一束光 |
| 门外是陆地 | 底部**树根之间的拱门直通池塘**，门外是荷叶和小码头 |

水口、记忆墙、任务公告板、书桌电脑这些都保留，布局和锚点和船屋**完全一样**，线框图可以直接用。

### 生图提示词（树洞版场景模块）

```
场景：一只小黄鸭的家，池塘边一棵古老大树的树洞内部，上下两层。墙壁是弧形的暖色木头内壁，能看到一圈圈年轮和树皮纹理，没有石头。
上层：高处有一个圆形的树节孔当窗户，透进一束柔和的光；树洞内壁上搭着一块木板阁楼，阁楼上有一张铺着蓝色被子的小床，一架绳梯垂到地面；阁楼旁的木壁上用麻绳和小木夹挂满明信片和拍立得照片。
中层：左边是嵌在树壁凹槽里的书架，塞满旧书和卷轴；中间是一张用树墩做的小书桌，桌上有一台小小的旧笔记本电脑，屏幕亮着几行代码，旁边有台灯和一杯热可可；右边壁上挂着一块软木任务公告板，钉着几张任务卡片和一张手绘地图。
下层：地面是被踩得平整的木头和几根粗壮的树根，中央是一块圆形草编地毯；左下角树根之间有一汪清澈的池水，漂着几片浮萍，水边放着一个小饭碗；右下方树根之间是一道拱形的门洞，门外能看到池塘、荷叶和一个小木码头。
最前景：几根弯曲的树根和芦苇，制造前后层次。
屋里散落着陶罐、干花、毛线团、小植物等手工小物件。不要画螺旋蘑菇台阶，不要画石头墙。床上、书桌前、地毯中央、水边和饭碗旁各留出一小块空位。画面四个角落保持简单，不放重要物件。
```
