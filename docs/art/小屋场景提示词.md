# 小屋场景生图提示词

> 目标：手绘绘本风、扁平上色、俯视角的竖屏小屋，像一张可以长时间看着的「生活切片」。
> 和 Qoder 第一次生成的那张（偏写实水彩、平视、光影很重）是两种方向。

---

## 0. 先避开的坑（版权）

参考图是一款已上市游戏的截图。我们要借鉴的是**通用的画风特征**，不是那款游戏本身：

- 提示词里**不要写**那款游戏的名字、开发商名，也不要写「XX 风格」。
- **不要照搬**它的标志性构图（树洞里的家、蘑菇台阶、青蛙、同款界面按钮）。
- 用我们自己的设定：**小黄鸭住在池塘边的小木屋**。画风相似、内容原创，才能放心提交。

---

## 1. 参考图的效果从哪来（写提示词时要抓住的点）

| 特征 | 参考图 | Qoder 第一次生成的图 | 提示词里怎么写 |
|---|---|---|---|
| 线条 | 统一粗细的深棕色描边，略带手抖感 | 几乎没有描边 | 深棕色细描边、手绘线条 |
| 上色 | 扁平色块，几乎没有渐变和高光 | 写实光影、体积感强 | 扁平上色、无渐变、无写实光影 |
| 视角 | 斜上方俯视，能看到整片地面 | 平视、像拍照 | 高角度俯视、等距感 |
| 构图 | 竖屏铺满，前景/中景/背景分层，有阁楼和梯子 | 一面墙的室内一角 | 竖屏、多层空间、阁楼 |
| 色调 | 低饱和：灰米色墙、木头棕、鼠尾草绿，点缀红橙蓝 | 暖黄偏饱和 | 低饱和、柔和、少量亮色点缀 |
| 氛围 | 手工感、杂而不乱、小物件很多 | 整洁的样板间 | 手工制作的家具、很多小物件 |

## 2. 主提示词

### 中文版

```
竖屏 9:16 游戏场景插画，一只小黄鸭的家：池塘边一间手工搭建的小木屋内部，没有角色。
高角度俯视视角，能看到大片地面，空间分前景、中景、背景三层；左上方有一个用木板搭的小阁楼，阁楼上放着一张铺着蓝色被子的床，一架木梯通到地面。
地面中央是一块圆形草编地毯；右侧靠墙是一个装满旧书的木书架；靠窗是一张小木桌，桌上有一台小小的旧笔记本电脑和一盏台灯；地上有一个印着小鸭子图案的饭碗；墙上有一扇圆形小窗，能看到外面的芦苇和池塘；右下角有一扇小木门。
墙上贴着便签、地图和手写纸条，屋里散落着陶罐、干花、毛线团、小植物等手工小物件，杂而不乱。
地面中央和门口附近留出空地，方便角色走动。
画风：手绘绘本插画，扁平上色，统一粗细的深棕色细描边，线条略带手绘的轻微抖动，几乎没有渐变和高光，没有写实光影；低饱和柔和配色，灰米色墙面、原木棕、鼠尾草绿为主，少量砖红、橙黄、雾蓝点缀；温暖、安静、治愈。
```

## 3. 游戏用图的要求（比好看更重要）

1. **背景里不要画鸭子。** 鸭子是单独的图层，要能在屋里走动。提示词已经写了「没有角色」，生成后再检查一遍。
2. **家具要和 Spec 对得上。** 第一阶段 Spec 里有 7 件家具：床、饭碗、书架、书桌（带小电脑）、窗户、地毯、门。图里每一件都要能找到，位置要分散，鸭子在它们之间走才好看。
3. **留出走路的空地。** 地面中间和门口不要堆东西。
4. **比例固定 9:16 竖屏**，和手机屏幕一致，前端直接铺满。
5. 选定一张后，让 Qoder 在图上标出每件家具的坐标（按图片宽高的百分比），写进 `src/data/`。

## 4. 同风格的其他素材

拿定稿的小屋图当**参考图**（垫图）一起喂给生图工具，风格才统一。

### 小黄鸭角色（透明背景）

```
一只圆滚滚的小黄鸭角色设计，正面、侧面、背面三视图，同一画风：手绘绘本插画，扁平上色，深棕色细描边，几乎没有渐变和高光，低饱和柔和配色，可爱、安静。纯白背景，方便抠图。
```

> 鸭子的形象如果要用 Qoder 官方的小黄鸭，以官方素材为准，只用这段提示词统一画风。

### 夜晚版本（鸭子睡觉时切换）

在主提示词末尾加：

```
夜晚，窗外是深蓝色夜空和星星，屋里只有一盏小油灯亮着，整体色调变暗变冷，但仍保持扁平上色、没有写实光影。
```

## 5. 调试小技巧

- 生成结果偏写实时：把「扁平上色、深棕色细描边、没有写实光影」挪到提示词**最前面**。
- 视角不够俯：加一句「从斜上方 45 度往下看，像在看一个微缩模型」。
- 太整洁、像样板间：加「生活痕迹很重，物品摆放随意」。
- 同一提示词多生成几张挑最好的，比反复改提示词更省时间。
