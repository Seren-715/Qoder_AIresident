# 美术素材：现状与规则

## 定稿规则（11-10 的教训）

1. **别连环改图。** GPT 每次「改图」其实是把整张图重新画一遍，改几次画风就会慢慢走样，细节也会越改越乱。一张图最多改 1 次；改坏了就回到上一张满意的，不再追。
2. **新素材一律从「风格基准图」出发，新开对话生成**，不要在改过很多次的对话里继续。
3. **屋内和屋外不追求严丝合缝。** 游戏里「屋里比屋外大」「门的位置对不太上」是很常见的惯例，玩家点门是切换场景，不会拿两张图对比。只要门外的景色大体对得上（有路、有池塘、有码头）就够了。
4. 时间很少，**背景图定稿后就不再动**，精力留给鸭子贴图和功能。

## 屋内鸭子锚点（试贴得到的建议值）

坐标是**鸭子脚底中心**相对背景图宽高的百分比；鸭子缩放系数：贴图原始尺寸 × 背景实际显示宽度 / 1672 × 0.33。

| 活动 | x % | y % | 脚下阴影 |
|---|---|---|---|
| `sleep` 床上 | 17.9 | 33.2 | 不要 |
| `read` 书桌前凳子 | 48.7 | 60.0 | 不要 |
| `code` 书桌前凳子（背影） | 48.7 | 60.0 | 不要 |
| `eat` 饭碗旁 | 25.6 | 85.9 | 要 |
| `gaze` 水池边 | 17.9 | 79.9 | 要 |
| `play` 地毯上 | 48.4 | 84.0 | 要 |
| `swim` 水池里（可选） | 10.2 | 88.2 | 不要 |

`leave`（背包出门）用在屋外场景，第三阶段再定位置。
