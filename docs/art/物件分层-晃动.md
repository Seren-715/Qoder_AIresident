# 物件分层：让物件单独晃动

> 11-12 更新。场景美术由 Claude 和 GPT 负责；Qoder 只负责把切好的图层摆上去、加上动效。
> 结论：**不用重新生图**。从定稿背景里把物件抠成独立贴图，再把它们身后的画面补上。

---

## 1. 为什么上次的风效会晕

11-10 那次（已撤回）用的是「同一张图的副本 + 羽化遮罩」：晃动的是**一块区域**，植物连同身后的墙和地面一起动，所以像画面局部在漂。

要让物件**单独**晃，它必须是独立图层：

| 层（从下到上） | 内容 |
|---|---|
| 背景 | 物件已被抹掉、画面已补好的底图 |
| 水效 | 现有的池塘水效 |
| 物件（后） | 吊饰、照片、云、布、远处的花草 |
| 鸭子 | 现有的鸭子精灵 |
| 物件（前） | 贴着画面下沿的前景植物，鸭子会被它们挡住一点 |
| 界面 | 气泡、按钮、面板 |

## 3. `props.json` 字段说明

位置都是相对**场景**宽高的百分比；支点是相对**贴图自身**宽高的百分比，直接用作 `transform-origin`。

| 字段 | 含义 |
|---|---|
| `image` | 贴图路径（相对 `public/`） |
| `left` `top` `width` `height` | 贴图在场景里的位置和大小（%） |
| `originX` `originY` | 变换支点（%） |
| `motion` | `swing` 绕支点旋转；`skew` 以支点所在的边为基准做水平斜切；`drift` 水平平移 |
| `trigger` | `hover` 鼠标滑过或点击时触发一次；`auto` 自动循环 |
| `amplitude` | 最大角度（度），左右对称 |
| `period` | 一个来回的秒数 |
| `delay` | 自动循环的起始延迟（秒，负数表示从中途开始），用来错开相位 |
| `travelFrom` `travelTo` | 云的**左边缘**从哪里走到哪里，单位是**场景宽度**的 %（不是贴图自身宽度） |
| `layer` | `back` 在鸭子后面；`front` 在鸭子前面 |

## 4. 三种动作

### 屋内：`swing` + `hover`（吊饰 3 件、照片 6 张）

- 鼠标滑过（手机上点一下）时，绕支点左右摆，**幅度逐渐衰减**，约 2.5 秒停下。
- 各自独立，互不带动；摆动期间再次滑过不重新开始。
- 吊饰挂在穹顶线上；照片绕夹子摆，**绳子和夹子的位置不动**（绳子留在底图里）。

### 屋外植物和布：`skew` + `auto`

- 植物的支点在根部（贴图下沿），布的支点在晾衣绳（贴图上沿）：固定一边，另一边轻轻偏。
- 幅度很小（1.5°～3°），缓入缓出，来回循环。
- **每个物件的周期和延迟都不一样**（已写在 `props.json` 里）。这是「自然」的关键：如果同步摆动，又会像一整块在动。

### 屋外：`swing` + `auto`（门口提灯）

- 绕挂钩小幅摆动（2.5°）。

### 屋外：云 `drift` + `auto`（11-13 重做）

第一版的云几乎看不出在动：移动范围只有场景宽度的 5%～7%，一个来回却要一分钟，约每秒 3 像素。现在改成**单向飘**：

- 云从大树树冠**后面**出来，向右匀速飘，飘出画面右边；然后回到树后重新开始。起点和终点都看不见，所以循环没有跳变。
- 速度约每秒 0.7%～1.1% 的场景宽度（1600 宽时约 11～18 像素/秒），三朵各不相同。
- `left` 从 `travelFrom` **匀速**变到 `travelTo`，用时 `period` 秒，无限循环；`delay` 是负数，保证一打开页面时云就在原图的位置上。
- **云层要套上天空遮罩**：把三朵云放进一个铺满场景的容器，给容器加 `mask-image: url(art/props/exterior/sky-mask.png)`，`mask-size: 100% 100%`（同时写 `-webkit-` 前缀）。这样云只在天空里显示，经过树冠和远山时自然被挡住。

**单位陷阱**：CSS 的 `translateX(10%)` 是相对**元素自身**宽度的，云的贴图只有场景的 7%～12% 宽，按这个写位移会缩小十倍，看起来就是不动。请直接对 `left` 做动画（单位是场景宽度的 %），或者用容器查询单位 `cqw`。

### 通用

- 系统设置了「减少动态效果」时，全部不动。
- 物件不能挡住家具、门、鸭子的点击热点（悬停响应只在屋内 9 件上需要）。

## 6. 没有切的东西，以及已知的小瑕疵

- **大树树冠、背景树林、菜园里的菜、门口两盆花**：没有切。树冠和树林面积大、和树干连在一起，抠不干净；盆花和树干、彼此之间互相遮挡。远景不动也符合常理。
- **草地上的植物是「整丛」切的**：叶子之间夹着的一点草地会跟着植物一起动。幅度只有 1.5°～2.5°，演示里看不出来；如果实际页面里觉得明显，把 `amplitude` 调小。
- **左下角的三丛植物（`plants-left`、`daisies`、`flowers-yellow`）互相挨着**，切口是直线。静止时无缝；摆动时相邻两丛之间最多错开约 2 像素。
- **屋内照片摆到最大角度时**，身后露出的墙面比周围略模糊（那里原本被照片挡住，是补出来的）。
- 底图里被物件挡住的部分都是补出来的，**单独看底图会有模糊的色块**，这是正常的，物件盖上去后看不到。

发现哪一件效果不好，告诉 Claude 是哪个 `id`，可以单独重切，不影响其他物件。
