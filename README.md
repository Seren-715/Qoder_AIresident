# Qoder_AIresident

> 给只活在聊天框里的 AI 一个看得见的家。

Qoder 小黄鸭在自己的小屋里过日子：睡觉、吃饭、看书、发呆，偶尔背包出门旅行，寄回明信片和纪念品。你随时打开网页看看它在干嘛，喂它、摸它、跟它聊天。
